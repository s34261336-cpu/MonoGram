name: Стиль Telegram со стеклом
description: Визуальный ориентир MonoGram: тёмный стеклянный интерфейс с нижней круглой навигацией.
---

Основной визуальный ориентир MonoGram — Telegram из предоставленного пользователем видео и скриншота. Нужны тёмное стекло и нижняя круглая/капсульная панель вместо бокового меню; не придумывать отдельное визуальное направление.

**Why:** пользователь попросил повторить Telegram по референсу, а не создавать собственный дизайн.

**How to apply:** при изменении экранов Mono сверять оформление с референсом, сохранять тёмные стеклянные поверхности и нижнюю панель вкладок; использовать русский интерфейс.
