name: Liquid Glass MonoGram
description: Полупрозрачные поверхности, синие акценты, светлая и тёмная темы.
---

Для MonoGram использовать визуальное направление iOS 26 Liquid Glass: мягкий градиентный фон, полупрозрачные поверхности с blur 24px / saturate 180%, тонкие светлые границы, мягкие тени и крупные скругления. Активная вкладка — синяя капсула #3390ec с тенью; FAB — синий градиент; пузыри сообщений — исходящие синие, входящие светлые, с хвостиками; поле ввода — стеклянное с круглой кнопкой отправки. Поддерживать светлую и тёмную темы через системную настройку, пока пользователь не попросит отдельный переключатель. Не менять логику при запросах только на стили. Интерфейс и подписи остаются русскими.

**Why:** это новый явно заданный пользователем визуальный курс; системная тема позволяет поддержать оба оформления без изменения логики приложения.

**How to apply:** для последующих визуальных изменений сохранять стеклянные поверхности и синие акценты в обеих темах; новые функциональные переключатели добавлять только по отдельному запросу.
